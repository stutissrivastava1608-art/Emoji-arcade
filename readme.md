# 🎰 EmojiSlots

**EmojiSlots – Spin. Match. Celebrate!**

EmojiSlots is an interactive three-reel arcade-style game built using vanilla HTML, CSS and JavaScript. It demonstrates asynchronous JavaScript, randomized outcomes, timer coordination and dynamic DOM manipulation through an engaging emoji-based interface.

## ✨ Features

- 🎰 Three animated emoji reels.
- 🎲 Randomized emoji selection.
- ⏱️ Independent reel animations using JavaScript intervals.
- 🛑 Coordinated stopping using timeouts.
- 🔒 Button locking to prevent multiple simultaneous spins.
- 🏆 Matching-symbol detection.
- 🎉 Animated win and result feedback.
- 📱 Responsive and interactive user interface.

## 🎯 Project Objective

The objective of EmojiSlots is to demonstrate advanced JavaScript concepts through an interactive arcade-style experience.

The project focuses on asynchronous programming, random array indexing, timer management, concurrency control and conditional logic.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling, animations and responsive design.
- **JavaScript (Vanilla)** – Game logic, randomization, timers and event handling.

## 🧠 JavaScript Concepts Demonstrated

| Concept | Application |
|---|---|
| `setInterval()` | Continuous reel animation |
| `clearInterval()` | Stopping reel animations |
| `setTimeout()` | Coordinating reel stops |
| `Math.random()` | Generating random outcomes |
| Array indexing | Selecting emoji symbols |
| Conditional statements | Checking matching outcomes |
| Button locking | Preventing concurrent spins |
| DOM manipulation | Updating reels and results |

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Press the Spin button.
5. Watch the three reels animate and reveal their results.

## 🎮 How It Works

1. The user initiates a spin.
2. The application locks the spin button.
3. Three reels begin displaying randomized emojis.
4. Each reel stops at a coordinated time.
5. JavaScript checks whether the resulting symbols match.
6. The application displays the appropriate result.
7. The spin button becomes available again.
